# 網頁爬蟲專題（`cr1.py`）

目前抓不到youtube連結
跟 經濟部工業區相關網站、觀音區戶政事務所、	臺灣文化記憶銀行
SSL 憑證驗證失敗

## 一、專案簡介

本程式以 Python
擷取指定網址的網頁資料，整理文章正文、圖片與頁面連結，並將爬取結果輸出成
Markdown、JSONL 與 CSV 檔案。

主要功能：

-   讀取 `input/urls.csv` 中的指定網址，並排除重複網址。
-   略過 YouTube 網址。
-   擷取網頁標題、網站名稱、正文、圖片與頁面連結。
-   清理常見網頁雜訊，例如導覽列、頁尾、廣告、Cookie
    提示、推薦內容及彈出視窗。
-   盡量保留文章標題、副標題、段落、條列、引用及表格內容。
-   嘗試擷取作者與發表日期；網頁未提供或程式無法辨識時，欄位會留空。
-   下載正文區域中的圖片，並依網頁分資料夾保存。
-   從原始指定網址尋找與觀音區相關的延伸連結，最多新增 10
    個網址，僅探索一層。
-   記錄網頁爬取結果、失敗原因及圖片下載狀態。

## 二、環境需求

-   Python 3.9 或更新版本（建議使用目前仍受支援的 Python 版本）
-   網路連線
-   Python 套件：
    -   `requests`
    -   `beautifulsoup4`

## 三、安裝方式

在終端機切換到 `cr1.py` 所在的專案資料夾，執行：

``` bash
python -m pip install requests beautifulsoup4
```

若電腦上有多個 Python 版本，也可以使用：

``` bash
py -m pip install requests beautifulsoup4
```

## 四、輸入網址格式

程式預設讀取：

``` text
input/urls.csv
```

CSV 檔案必須包含 `url` 欄位，也可以包含 `category` 欄位。例如：

``` csv
url,category
https://example.com/article-1,新聞
https://example.org/page-2,文化
```

請將範例網址換成實際要爬取的網址。網址必須以 `http://` 或 `https://`
開頭。相同網址只會保留一次；YouTube 網址會被略過。

## 五、執行方式

在專案資料夾中執行：

``` bash
python cr1.py
```

Windows 環境也可以執行：

``` bash
py cr1.py
```

程式執行期間會在終端機顯示處理進度。完成後會列出網頁成功／失敗數、延伸探索數、圖片找到數及圖片下載成功／失敗數。

## 六、輸出資料夾與檔案

執行結果預設存放在：

``` text
output/
└── standard_crawl/
    ├── articles/
    │   ├── page_001.md
    │   ├── page_002.md
    │   └── ...
    ├── images/
    │   ├── page_001/
    │   │   ├── image_001.jpg
    │   │   └── image_002.png
    │   ├── page_002/
    │   │   └── image_001.webp
    │   └── ...
    ├── index.jsonl
    ├── crawl_report.csv
    └── crawler.log
```

### 輸出檔案說明

  ------------------------------------------------------------------------------------------
  檔案／資料夾                        用途
  ----------------------------------- ------------------------------------------------------
  `articles/`                         每個網頁的 Markdown
                                      結果，包含基本資料、清理後正文、圖片資訊與頁面連結。

  `images/page_NNN/`                  每個網頁下載的圖片各自存放於對應資料夾。

  `index.jsonl`                       每筆爬取紀錄一行
                                      JSON，保存正文、圖片、連結、狀態等資料。

  `crawl_report.csv`                  爬取摘要報表，可用試算表軟體查看。

  `crawler.log`                       執行過程、成功紀錄、失敗原因及圖片下載錯誤等訊息。
  ------------------------------------------------------------------------------------------

`page_NNN` 是本次執行時的網頁處理編號，例如 `page_001`。Markdown
檔案與圖片資料夾使用相同編號，方便對照。

## 七、正文清理策略（任務 2）

程式先使用 CSS 選擇器移除常見的非正文元素，再嘗試依常見 HTML
結構選取主要內容區塊，最後擷取可閱讀的文字。

### 7.1 嘗試移除的內容

-   `script`、`style`、`noscript`、`iframe`
-   導覽列、頁尾、側欄、表單及按鈕
-   常見廣告、橫幅、促銷內容
-   Cookie 提示、社群分享區塊
-   推薦文章、相關內容
-   訂閱區塊、彈出視窗及浮動區塊

### 7.2 嘗試保留的內容

-   標題及副標題（`h1` 至 `h4`）
-   正文段落、條列、引用
-   表格列與儲存格文字
-   主要正文區域中的圖片資訊及圖片說明
-   作者、發表日期等可從常見 HTML metadata 辨識的資訊

### 7.3 正文區塊辨識

程式會依序嘗試
`article`、`main`、`[role="main"]`、`.article-content`、`.article-body`、`.post-content`
等常見選擇器。如果找不到符合條件的區塊，就退回使用 `body`
或整個頁面作為備援。

### 7.4 清理策略的限制

不同網站的 HTML
結構與命名方式不一致，因此清理屬於啟發式方法，不能保證所有雜訊都被移除，也可能誤刪部分正文。作者、日期、圖片說明等資訊也只有在網頁提供且程式能辨識時才會擷取。

建議抽查不同類型網站的 Markdown
結果，確認正文是否完整、是否仍有導覽或推薦內容混入。作業要求的「至少三種網站原始網頁截圖與清理結果對照」仍須另外整理，不能只以程式執行成功取代。

## 八、延伸探索規則

程式會從原始指定網址的連結中，檢查連結文字或網址是否包含下列關鍵字：

-   `觀音`
-   `草漯`
-   `白沙岬`
-   `甘泉寺`
-   `觀音山`
-   `觀音區`

最多新增 10 個符合條件的延伸網址，延伸探索深度設定為
1。延伸頁面不會再繼續尋找下一層連結。

## 九、錯誤紀錄與排查

### 找不到 `urls.csv`

確認檔案位於：

``` text
input/urls.csv
```

並確認 CSV 第一列有 `url` 欄位。

### 網頁爬取失敗

可能原因包括：

-   網站無法連線或逾時。
-   網站回傳 HTTP 錯誤狀態碼。
-   網站的 SSL 憑證驗證失敗。
-   網站限制自動化請求或需要 JavaScript 才能顯示內容。

請查看 `crawler.log` 及 `crawl_report.csv`
中的失敗原因。程式不會將失敗頁面假裝成成功。

### 圖片下載失敗

圖片可能有防盜連、登入限制、網址失效或伺服器拒絕請求等情況。單張圖片大小上限為
20 MB。圖片下載失敗不代表整個網頁爬取失敗，請查看 Markdown 的圖片資訊或
`index.jsonl` 中的下載狀態與原因。

### 清理後正文不完整或混入雜訊

不同網站使用的 HTML 結構不同。請查看 Markdown
內的「正文選擇器」欄位，並對照原始網頁檢查。若網站使用特殊的正文容器，需要再為該網站調整選擇器。

## 十、注意事項

-   請遵守目標網站的使用條款、`robots.txt`
    與相關法律規範，避免過度頻繁請求。
-   本程式會依設定在網頁請求之間加入延遲；圖片下載也會加入短暫延遲。
-   每次執行會重新寫入 `index.jsonl` 與
    `crawl_report.csv`，但既有文章或圖片檔案可能仍留在輸出資料夾。若要取得乾淨的一次性結果，建議先備份後清理舊輸出資料。
-   YouTube 網址會被略過；本版本不負責下載 YouTube 字幕或影片畫面。
